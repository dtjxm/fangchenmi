# 智慧守护

给家庭自己用的 Android 应用时长管控工具。装在家长的手机上，孩子拿去玩的时候，哪些应用计入时间、每天多少分钟、到几点必须停，都由家长设定。

不是监控软件：没有账号、不联网上报、不读取屏幕内容，所有数据只存在本机。

## 直接下载

**[智慧守护 v1.3.6 · app-release.apk](./app-release.apk)** — 4.75 MB，要求 Android 8.0 及以上

点开链接下载安装。首次安装需要在系统设置里允许「安装未知来源应用」。也可以在 App 内「设置 → 关于 → 检查更新」升级。

## 它做什么

- **一个总额度**：所有受保护的应用共用一个每日时长，玩哪个都从里面扣
- **只算真正在玩的时间**：受保护应用在前台 + 屏幕亮着 + 未锁屏才计时。计算器、时钟、文件管理这类工具，以及微信、QQ、电话不计入
- **额度用完就锁**：弹出全屏页面，返回键无效，只能找家长输密码加时
- **夜间硬锁**：设定一个时段（默认 21:30 – 06:30）到点强制休息，答题也解不开
- **新应用自动纳入**：新装的应用默认受保护，不用家长手动添加
- **可一键切换**：应用管理页有「全部娱乐类」开关，只批量选中游戏、短视频这类，跳过系统工具和通信应用

## 需要开的两个权限

| 权限 | 用途 |
|---|---|
| 无障碍服务 | 识别当前前台是哪个应用 |
| 使用情况访问 | 无障碍失效时的备用判断依据 |

两者都只用来判断「孩子现在在用哪个应用」，不读取屏幕内容，也不上传任何数据。
